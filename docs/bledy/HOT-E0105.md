# HOT-E0105 — oficjalny instalator Horizona nie zadziałał

## Znaczenie
Oficjalny `install.sh` Horizona (z `horizon-rust/horizon`, gałąź main) nie zainstalował wybranego Nightly do `/srv/horizon/horizon`.

## Typowe przyczyny
1. Brak sieci do GitHuba.
2. Tag z `--horizon-version` nie istnieje albo został usunięty.
3. Suma kontrolna pobranego archiwum się nie zgadza.

## Diagnostyka
- `curl -fsSL https://api.github.com/repos/horizon-rust/horizon/releases/tags/<tag>` — czy tag istnieje.
- Pole `chain` wpisu ma wyjście `install.sh`.
- `ls -l /srv/horizon/horizon/current`.

## Naprawa
Sprawdź tag na https://github.com/horizon-rust/horizon/releases i uruchom instalator z `--horizon-version TAG`. Przy błędzie sumy kontrolnej pobierz ponownie; nie wyłączaj sprawdzania.

## Co system robi sam
Wydanie Horizona, które było w użyciu, zostaje. Kolejne kroki nie ruszają.

## Kod
- `scripts/server-install.sh` (`horizon`)
