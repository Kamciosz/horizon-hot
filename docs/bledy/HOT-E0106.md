# HOT-E0106 — horizon-hot nie buduje się na serwerze

## Znaczenie
Instalator nie pobrał albo nie zbudował `hotd`, `hot-core` i `hot-diag` ze źródeł horizon-hot. Kontekst `step` mówi, który etap padł: `rustup`, `clone`, `fetch`, `ref` albo `cargo`.

## Typowe przyczyny
1. `rustup`, `clone`, `fetch`: brak sieci.
2. `ref`: literówka w `--hot-ref` albo usunięta gałąź.
3. `cargo`: za mało pamięci, brak `build-essential`, kod z danej wersji się nie kompiluje.

## Diagnostyka
- `sudo -u horizon -H git -C /srv/horizon/src/horizon-hot log -1`.
- `free -m` w trakcie budowy.
- Pole `chain` wpisu ma ostatnie linie `cargo` albo `git`.

## Naprawa
Napraw to, co pokazuje `chain`, i uruchom instalator ponownie. Kod, który się nie kompiluje, naprawia się w repo horizon-hot, potem `--hot-ref` z poprawką.

## Co system robi sam
Poprzednio zbudowana wersja (`/srv/horizon/hot-version`) zostaje w użyciu.

## Kod
- `scripts/server-install.sh` (`hot_build`)
