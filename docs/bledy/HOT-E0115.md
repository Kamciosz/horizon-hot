# HOT-E0115 — kontener nie zna repo serwera

## Znaczenie
Kontener wystartował bez `HOT_REPO`. To adres repo serwera z modami, które pobiera `hotd`. Bez niego kontener niczego nie uruchamia i kończy pracę z kodem 3, czyli czeka na właściciela. To nie jest awaria.

## Typowe przyczyny
1. Pierwszy start z przykładowym `compose.yaml`, w którym `HOT_REPO` jest puste.
2. Zmienna jest ustawiona w innym pliku niż ten, z którego startuje `docker compose` (np. `.env` w innym katalogu).

## Diagnostyka
- `docker compose config | grep HOT_REPO` — wartość, którą kontener faktycznie dostaje.
- `docker compose logs server | tail` — ostatnia linia z kodem `HOT-E0115`.

## Naprawa
Wpisz w `compose.yaml` adres repo: `https://github.com/<właściciel>/<repo>` dla repo publicznego albo `git@github.com:<właściciel>/<repo>.git` dla prywatnego. Potem `docker compose up -d`. Przy adresie SSH kontener przy starcie wypisze klucz tylko do odczytu; dodaj go w repo w Settings → Deploy keys.

## Co system robi sam
Nic. Nie zgaduje adresu i nie startuje serwera bez repo. `restart: unless-stopped` ponawia start co kilka sekund, a każdy start kończy się tym samym kodem, dopóki zmienna jest pusta.
