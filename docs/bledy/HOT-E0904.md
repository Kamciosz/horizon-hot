# HOT-E0904 — logowanie kontem Microsoft się nie udało

## Znaczenie
Przy pierwszym uruchomieniu w launcherze nie ma konta, więc `hot-play` uruchamia `horizon-launcher account sign-in` (kod urządzenia: gracz wpisuje kod na stronie Microsoftu). Po nim nadal nie ma konta albo polecenie zwróciło błąd. Gra i serwer wymagają konta z kupionym Minecraft: Java Edition; nic tego nie omija.

## Typowe przyczyny
1. Gracz przerwał logowanie albo kod wygasł.
2. Konto nie ma kupionego Minecraft: Java Edition.
3. Brak internetu.

## Diagnostyka
- Plik `hot-play.jsonl` w folderze logów `hot-play` (macOS: `~/Library/Application Support/hot-play/logs`, Linux: `~/.local/share/hot-play/logs`, Windows: `%LOCALAPPDATA%\hot-play\logs`). „Napraw” zapisuje z niego raport `hot-play-raport.md` na pulpicie.
- `horizon-launcher account list --json` pokazuje konta i stan logowania.

## Naprawa
Wybierz „Graj” jeszcze raz i zaloguj się kontem, na którym kupiono grę.

## Co system robi sam
Pyta o logowanie tylko wtedy, gdy w launcherze nie ma żadnego konta.

## Kod
- `crates/hot-play/src/game.rs` (`graj`)
- `crates/hot-play/src/real.rs` (`signed_in`, `sign_in`)
