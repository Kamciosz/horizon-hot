# HOT-E0906 — nie da się ustawić instancji gry

## Znaczenie
`hot-play` gra we własnej instancji launchera `horizon-hot` (osobny folder gry, osobna lista serwerów). Nie udało się jej założyć, przypiąć do wersji albo zapisać w niej pliku (`horizon-mods.txt`, `servers.dat`, `horizon-mods/hot_slots.hmod`).

## Typowe przyczyny
1. Brak miejsca na dysku albo uprawnień do folderu launchera.
2. Launcher odmówił `instance create` albo `instance version`.

## Diagnostyka
- Plik `hot-play.jsonl` w folderze logów `hot-play` (macOS: `~/Library/Application Support/hot-play/logs`, Linux: `~/.local/share/hot-play/logs`, Windows: `%LOCALAPPDATA%\hot-play\logs`). „Napraw” zapisuje z niego raport `hot-play-raport.md` na pulpicie.
- `context.path` wskazuje plik, którego nie zapisano.
- `horizon-launcher instance list --json` pokazuje instancje i ich foldery.

## Naprawa
Zwolnij miejsce, potem „Napraw”. Gdy instancja jest zepsuta, usuń ją w launcherze (`instance delete horizon-hot`); „Graj” założy nową.

## Co system robi sam
Przy każdym „Graj” porównuje pliki z oczekiwanymi i zapisuje tylko różniące się, przez plik tymczasowy.

## Kod
- `crates/hot-play/src/real.rs` (`instance`, `create_instance`, `pin_version`, `write`)
