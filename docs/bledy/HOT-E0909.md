# HOT-E0909 — `hot-play` się nie zaktualizował

## Znaczenie
Przy starcie `hot-play` nie sprawdził, nie pobrał albo nie wstawił nowej wersji z wydania `hot-play` na GitHubie. Program działa dalej na obecnej wersji. To błąd tylko w logu, gry nie zatrzymuje.

## Typowe przyczyny
1. Brak internetu albo GitHub nie odpowiada.
2. Pobrany plik ma inną sumę SHA-256 niż `SHA256SUMS` (przerwane pobieranie albo wydanie właśnie się zmienia).
3. Folder danych `hot-play` jest tylko do odczytu albo plik programu jest zablokowany (antywirus na Windows).

## Diagnostyka
- `hot-play.jsonl` w folderze logów `hot-play` (macOS: `~/Library/Application Support/hot-play/logs`, Linux: `~/.local/share/hot-play/logs`, Windows: `%LOCALAPPDATA%\hot-play\logs`): pola `url`, `file`, a przy złej sumie `expected` i `got`.
- `curl -fsSL <url>/SHA256SUMS` pokazuje, czy wydanie zna ten plik.

## Naprawa
Zwykle nic: następny start spróbuje znowu. Gdy błąd się powtarza, uruchom instalację jeszcze raz (README, sekcja „Gracze”).

## Co system robi sam
Zostaje na obecnej wersji i próbuje przy każdym starcie. Stary plik zostaje na miejscu, dopóki nowy nie przejdzie sprawdzenia sumy.

- `crates/hot-play/src/update.rs` (`check`, `replace`)
- `crates/hot-play/src/bin/hot-play.rs` (`self_update`)
